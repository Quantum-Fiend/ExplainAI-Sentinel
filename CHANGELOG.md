# Changelog

All notable changes to the **ExplainAI-Sentinel** platform will be documented in this file.

## [1.0.0] - 2025-12-26
### Added
- **Core Runtime (Go)**: Service registry, monitoring, and HTTP API.
- **Networking (Java)**: Secure Netty message broker.
- **Logging (C)**: High-performance lock-free ring buffer log engine.
- **AI Engine (Python)**: Explainable Anomaly Detection, SHAP/LIME integrators.
- **Knowledge Graph (Scala)**: Spark GraphX causal reasoning engine.
- **Policy Engine (Rust)**: Zero-Trust evaluator with trust scoring.
- **Dashboard (TS/React)**: Real-time visualization UI.
- **Deployment (Ruby)**: Docker & K8s orchestration logic.
- **Data Pipeline (Kotlin)**: Kafka Streams ETL processor.
- **Monitoring**: Prometheus and Grafana pre-built dashboards.
- **CI/CD**: GitHub Actions workflows for polyglot testing.

### Features
- Real-time explainable AI security analysis.
- Distributed causal reasoning for incident forensics.
- Polyglot orchestration across 9 languages.
- Production-ready Kubernetes manifests.
